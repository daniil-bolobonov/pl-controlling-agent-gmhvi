### Categories

| Category                   | What gets built                                                                                   | Asset Type|
|----------------------------|---------------------------------------------------------------------------------------------------|-----------|
| **Vercel/v0 Frontend App** | Standalone frontend web app (dashboard, portal, landing page, internal tool) generated by the external Vercel v0 partner from the specification. Recommend when the deliverable is a **UI artifact** with no required SAP backend logic — files are synced back as a `vercel-app` asset and iterated via the partner, not hand-edited. |`vercel-app`|

### Decision Flow

- Is the deliverable a standalone frontend web app (dashboard, portal, landing page, internal tool) with no required SAP backend logic — i.e. a pure UI artifact? → **Vercel/v0 Frontend App**
